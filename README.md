# AIBO v7

Cline ルール設定完了 ✅ - 2026/05/16

## 初回セットアップ (1 回だけ)

`setup_desktop_shortcut.bat` をダブルクリック → デスクトップに
「AIBO Cyber Studio」ショートカットが作成されます。

## 通常起動

デスクトップの「AIBO Cyber Studio」アイコンをダブルクリック。

## 起動方法 (PC · 手動)

ワンクリック起動: `start_aibo.bat` をダブルクリック

手動起動:
1. `cd frontend && npm run dev`
2. ブラウザで http://localhost:3000
