# フェーズゲート(完了の定義)

「完了」と言ってよいのは、完了条件を**検証で満たしたとき**だけ。実装が終わった ≠ 完了。

## ゲート(全て通るまで完了禁止)
1. 指示書の「完了条件」を1つずつ列挙し、各々が満たされたか**証拠付き**で確認する。
2. 変更した .py は `python -m py_compile` を通す。
3. エラー修正なら、報告されたエラーが**再現しない**ことを確認(条件を示す)。
4. 厳守ルールに全て準拠していることを確認(setting-a-guard / 禁止事項)。
5. スコープ外の変更を巻き込んでいないこと。

## 禁止
- 検証していない項目を「完了」と書くこと。
- happy-path だけ確認して「テスト済み」と言うこと。
- 厄介な問題を黙ってスキップして完了報告すること(silent skip)。
- `try/except: pass` で例外を握りつぶして「動いた」とすること。

## 未達のとき
完了条件を満たせない項目があれば、「完了」とせず**保留として明記**し、何が・なぜ未達かを
報告して司令部の判断を仰ぐ(aibo-report 参照)。
