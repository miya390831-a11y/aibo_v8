## 結果(要点・専門用語控えめ)
1. **faces_detected=0 は「顔が見つからなかった」ではない。** 参照画像1枚(single)の経路では、この
   カウンタを**そもそも一度も更新しない**作りになっている(更新するのは複数枚の品質計算経路だけ)。
   → この数字は今回の検出結果を表していない。判断材料にしてはいけない(OBS-001 §5 の強化版)。
2. **PuLID が乗らない真因は、顔から ID を取り出す抽出器が「空(None)」を返したこと。**
   参照画像はクロップ工程(Sniper)で消えていない(Sniper は失敗時も元画像を返す設計)。
3. **最有力は、PuLID 抽出器の専用ロード(lazy_init)の失敗**。これは「PuLIDFluxPipeline(正常)」とは
   **別物**で、独立に顔モデル(InsightFace/EVA-CLIP/BiSeNet)や PuLID 重みを読む。ここが失敗すると
   30秒の再試行抑止(cooldown)が効き、その間の生成は静かに PuLID 無しになる。
4. **黙って握り潰す箇所は無い**。失敗は全部エラーログ + 理由文字列に残る。**ただし OBS-C がその理由を
   出さない**ので「静かに失敗」に見えるだけ(=観測の穴)。
