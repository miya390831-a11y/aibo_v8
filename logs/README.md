# AIBO Cyber Studio · Logs Directory

Claude Code が実行した全タスクの完了報告を蓄積する場所。

## 命名規則

```
report_<タスク番号>_<YYYYMMDD>_<HHMMSS>.md

例:
  report_001_20260524_063015.md       タスク #001 (Setting A)
  report_001_5_20260524_065200.md     タスク #001.5 (デスクトップアイコン)
  report_001_6_20260524_071000.md     タスク #001.6 (bypass モード)
  report_001_7_20260527_181000.md     タスク #001.7 (本ルール設定)
  report_005_20260524_090000.md       タスク #005 (Pose Templates)
  report_002_phase_a_20260524_120000.md
  report_006_a1_poc_day1_20260530_180000.md
```

タイムスタンプ生成 (PowerShell):
```powershell
Get-Date -Format "yyyyMMdd_HHmmss"
```

タイムスタンプ生成 (bash):
```bash
date +%Y%m%d_%H%M%S
```

## 簡易版テンプレート (軽微タスク用)

10 分未満かつコード変更なしの場合のみ使用可:

```markdown
# タスク #XXX 完了報告 (簡易版)

**実行日時**: YYYY-MM-DD HH:MM:SS
**内容**: <1-2 行で要約>
**変更ファイル**: <ファイル名 + md5>
**Git**: <commit hash>
**所感**: <あれば 1 行>
```

コード変更を伴うタスクは**必ず標準テンプレート**を使用すること。

## PO との共有フロー

```
1. Claude Code がタスク完了
   ↓
2. report_XXX.md が自動で logs/ に作成される
   ↓
3. Claude Code が画面に「report_XXX.md 保存完了」と表示
   ↓
4. PO はファイルを Claude チャット (Web 版) にアップロード
   ↓
5. Claude (Opus 4.7) が分析・次のアドバイス
```

## .gitignore の扱い

- `logs/` ディレクトリは Git 追跡 (`.gitkeep` で空でも含める)
- 個別の `report_*.md` も追跡 (作業履歴として保全)
- `logs/*.tmp` / `logs/*.lock` は `.gitignore` で無視
- 100 件超えたら月次アーカイブ推奨: `logs/archive_YYYYMM/` に移動
